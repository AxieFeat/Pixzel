# Исправления Cristalix, 25 октября 2026

Исправлена копия меню по повторно приложенному видео 2560×1440, 60 кадров/с, 71,27 с. Сравнивались основной экран, hover, прокрутка, список отзывов, отзывы режима и форма написания отзыва.

## Поведение и геометрия

- Две полоски баннера заполняются по времени и переключаются вместе со слайдами.
- Баннер и карточки находятся в одном контейнере и используют одно смещение прокрутки. У карточек устранена дополнительная пружина, вызывавшая отставание.
- Hover, затемнение, надпись «ИГРАТЬ» и подсказка появляются в первый кадр наведения. Убраны задержка и всплывание подсказки.
- Оригинальный пользовательский `corner.png` скопирован в ресурсы без изменения; окраска и отражения выполняются при отрисовке всех четырёх углов.
- Звезда, включая сохранённое избранное, скрыта без наведения или клавиатурного фокуса.
- Подложка закреплённой панели пропускает карточки при прокрутке. Исправлены интервалы сетки и накопление вертикального смещения рядов.
- В отзывах восстановлена первая широкая карточка, исправлены размеры текста и формы, вертикальное размещение абзацев, иконок и подписей. Убраны отсутствующие в шрифте символы поиска и карандаша.
- Перемещение указателя с открытой подсказкой меняет только трансформацию, без повторного измерения всего меню.

## Производительность

Причины избыточной работы: сглаживание через поверхность 5120×2880, полноэкранные группы даже для полностью прозрачных элементов, отрисовка карточек за экраном, постоянная перерисовка статичных элементов и многократный расчёт всей сетки отзывов при измерении каждой карточки.

Для пиксельного демо используется рендер 1×. Прозрачные поддеревья не отправляются на GPU, сохраняя обновления и возможность снова появиться. Карточки за экраном отсеиваются; каталог скрывается под открытой страницей отзывов. Повторное присваивание неизменившейся прозрачности не запускает перерисовку. Раскладка отзывов рассчитывается один раз за проход. Живой цикл ограничен 60 кадрами/с независимо от настроек драйвера.

На RTX 4060 Ti / NVIDIA 617.42, OpenGL 4.1, JDK 21.0.10:

| Hover | 7,035 мс | 7,605 мс | 166 | 1 |

Это 240 измерений после 60 кадров прогрева с `glFinish`, включая ожидания драйвера; другие приложения оставались открыты. В более раннем проходе медианы меню/отзывов были 1,4–2 мс: видны влияние планировщика GPU и ожидания драйвера. Результаты не являются универсальной гарантией FPS.

Одна поверхность рендера занимает 29 491 200 байт (28,125 МиБ). Это не вся видеопамять процесса. Отдельно измеренный **живой процесс** через Windows GPU Process Memory занимал **215 248 896 байт, около 205 МиБ VRAM**. Шесть секунд GPU Engine: **10,73–27,75%**, среднее около **19%**. Исходные заявленные пользователем 500 МБ/50% не являются нашим замером предыдущей версии. Сырые результаты: `build/cristalix-live-gpu.json`, `pixzel-demo/build/reports/cristalix/profile-*.txt`.

На статичной странице отзывов после прогрева: 0 измеренных узлов, 0 перерисованных узлов, 0 загруженных байт за кадр. В меню перерисовывается баннер с движущимся индикатором.

## Попиксельное сравнение

`tools/cristalix/compare_reference.py` извлекает исходные кадры и сохраняет наложения 50/50 и усиленную разницу без масштабирования или совмещения изображений. Исходные кадры и захваты должны быть ровно 2560×1440.

```powershell
python tools/cristalix/compare_reference.py '<video.mp4>' --ffmpeg '<ffmpeg.exe>'
```

Результаты находятся в `build/cristalix-comparison/`: `overlay-menu.png`, `overlay-hover.png`, `overlay-game-reviews.png`, `overlay-review-compose.png`, `overlay-reviews.png` и `comparison.json`.

Проверка цветовых границ при x=610: первый ряд в видео и копии занимает y=[460,758), второй — y=[777,1076). Полного совпадения каждого пикселя нет: различаются фоновая игровая сцена, сжатие записи, сглаживание шрифтов, фаза рекламы, курсор и демонстрационные данные отзывов.
